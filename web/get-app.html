Kaye for Android

1

Download

Download kaye.apk

Version 1.0.0 · about 20 MB · Android 8.0 or newer

2

Install

Open the file and allow your browser to install apps when Android asks. Kaye is signed with its own release key.

3

Start

Tap Try it now, no account, keep “Load a sample notebook” on, and open Snap to read a sample page.

4

On-device AI

On phones with Gemini Nano (AICore: Pixel 9/10, Galaxy S25 and others), go to Settings → Get Gemini Nano. Pages are then read on the phone. Other phones ask before using the cloud.

Judges: the demo account demo@petiht.com / KayeDemo509 works in the app and on the web. Sample data is invented.
